# Pulsetto Growth Audit

**Live → https://eddieatadapty.github.io/pulsetto-flow-rebuild/**

Five ideas to turn more Pulsetto users into subscribers, each built into a clickable version of Pulsetto's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Use the two answers you already have | +10–20% CR to purchase |
| 02 | Let them feel it work before you charge | +10–15% CR to purchase |
| 03 | Sell what they can use tonight | +5–15% CR to purchase |
| 04 | Fix the broken price, then make the saving obvious | +10–15% ARPU from annual mix |
| 05 | Catch the people who close the paywall | +10–15% ARPU |

Every price, rating and feature comes from Pulsetto's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Pulsetto. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
